### 🚀 Counting Paths Coding Challenge

**counting-paths-coding-challenge** Counting paths is a coding challenge where you navigate a grid, counting unique ways to reach the destination. You'll tackle obstacles, aiming to devise an efficient algorithm, usually through recursion or dynamic programming, to calculate valid paths. It's a digital maze-solving exercise that hones your problem-solving and algorithmic skills.

## Getting Started [![Build Status](https://github.com/R4Ajeti/counting-paths-coding-challenge/actions/workflows/counting-paths-unit-tests.yml/badge.svg)](https://github.com/R4Ajeti/counting-paths-coding-challenge/actions)

**Running tests**</br>
Clone the repository to your local machine to get a copy running on your local machine.

```
git clone counting-paths-coding-challenge
cd counting-paths-coding-challenge
```

Install dependencies (<small>hint: if you want to use a virtual environment, create one first</small>)</br>
$ `pip install -r requirements.txt`

Run tests</br>
$ `pytest tests/* -vv`
